# Student-Data-Analysis-Dashboard
# Project Overview
The Student Data Analysis Dashboard is an interactive Power BI report designed to analyze student enrollment, course distribution, revenue, and certification trends. It provides insights into student behavior, popular courses, and overall performance metrics.


## Objectives
- Analyze total student enrollment
- Track revenue generated from courses
- Identify popular courses
- Understand age group distribution
- Monitor monthly course trends
- Evaluate certification completion rate

## Tools & Technologies Used
- **Power BI Desktop** – Dashboard creation and data visualization
- **DAX (Data Analysis Expressions)** – For calculated columns and measures
- **Power Query** – Data cleaning and transformation
- **Excel / CSV** – Source data

  ---

##  Insights
- Courses like DaVinci Resolve and Adobe After Effects generate high revenue
 - Most students belong to the 20–29 age group
-  Peak enrollments occur in specific months (e.g., November)
-  Certification completion is moderate compared to total students
